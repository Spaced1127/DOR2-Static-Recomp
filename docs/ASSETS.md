# Branding and asset policy

## Launcher artwork (SteamGridDB — user-approved policy override)

By explicit user decision (2026-11-11), the launcher ships **SteamGridDB artwork**
for WWE Day of Reckoning 2, overriding the original-art-only policy below for
these assets only. This is copyrighted WWE/THQ/Nintendo material; the user
accepted the associated risk for this public release. Sources (SteamGridDB,
game id 17046):

- Background: `assets/sgdb/dor2_grid.png` — cover art,
  https://www.steamgriddb.com/game/17046/grids
- Header logo: `assets/sgdb/dor2_logo.png` — by Just.Seani,
  https://www.steamgriddb.com/logo/45382
- Icon: `assets/sgdb/dor2_icon.png` — by Ahmer_Jdj,
  https://www.steamgriddb.com/icon/123924 (converted to `assets/dor2.ico`)

The launcher loads the grid/logo at runtime and falls back to procedural arena
art when they are absent. `assets/make_icon.ps1` is retained as an original-art
fallback icon generator. All other game data (disc, DOL, textures, audio, saves)
remains excluded.

## Original-art fallback (default policy)

Absent the override above, this repository ships no extracted game art, logos,
textures, character renders, music or cover art. The fallback release icon is
original artwork generated by `assets/make_icon.ps1` (ring ropes, corner posts
and the text "DOR2"). It does not use WWE logos or wrestler likenesses.

To regenerate the icon:

```powershell
powershell -ExecutionPolicy Bypass -File assets\make_icon.ps1
```

Requires Windows PowerShell and `System.Drawing`. The script writes
`assets/dor2.ico` with 16/24/32/48/64/128/256 px entries. The ICO is committed
so the build does not need to regenerate it.

## Executable resources

`assets\launcher.rc`, `runner.rc`, `runner-core.rc` and `prepare.rc` embed the
icon and version info (`0.1.1.0`) into each Windows executable. They are attached
from the top-level `CMakeLists.txt`; upstream runtime sources are untouched.

Verify after a build:

```powershell
Add-Type -AssemblyName System.Drawing
[System.Drawing.Icon]::ExtractAssociatedIcon("build\moderngekko\DOR2Recomp.exe").ToBitmap().Save("icon-check.png")
```

## Runtime data (`Sys/`)

`Sys/` is copied from the pinned ModernGekko/Dolphin runtime at build time. It
contains shader data, game settings and the DSP firmware files
(`Sys/GC/dsp_rom.bin`, `dsp_coef.bin`) required for DSP LLE audio. These are
runtime files supplied by the upstream project, not game content. They are
included because the runner fails to boot audio without them.

## Fonts

No font files are shipped. The icon uses Arial Black from the host system at
generation time; the resulting raster is original artwork.
